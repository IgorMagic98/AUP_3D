Структура проекта
AUP_3D_Builder/
├── index.html              # Главный HTML-файл
├── styles.css              # Стили интерфейса
├── state.js                # Глобальное состояние и константы
├── engine.js               # 3D-движок (Three.js)
├── factory.js              # Фабрика создания 3D-объектов
├── world.js                # Управление сценой (земля, сетка, оси)
├── tree.js                 # Дерево объектов (левая панель)
└── modules/
    ├── project-manager.js  # Управление проектами
    ├── scene-manager.js    # Управление камерой и видом
    ├── pipeline-builder.js # Построитель трубопроводов
    ├── object-editor.js    # Редактор объектов
    ├── split-manager.js    # Разбиение трубопроводов
    ├── network-graph.js    # Граф сети (визуализация)
    ├── visual-effects.js   # Визуальные эффекты
    ├── input-handler.js    # Обработка ввода (мышь, клавиатура)
    └── ui-app.js           # Главный координатор (UI)

1. index.html - Точка входа
Что делает:
    Подключает все библиотеки (Three.js, Bootstrap)
    Содержит всю HTML-разметку интерфейса (ribbon-меню, модальные окна, canvas)
    Определяет порядок загрузки скриптов
    Инициализирует приложение при загрузке страницы

2. state.js - Глобальное состояние
Что хранит:
    CONFIG - настройки (цвета, диаметры труб, качество геометрии)
    STATE - текущее состояние приложения (объекты на сцене, счетчики, активные режимы)
    Utils - вспомогательные функции (clamp, showStatus)
    genNodeId() - генератор уникальных ID для узлов

3. engine.js - 3D-движок
Отвечает за:
    Создание сцены Three.js
    Настройку камеры и рендерера
    OrbitControls (вращение камеры мышью)
    Освещение
    Цикл анимации (requestAnimationFrame)

4. factory.js - Фабрика 3D-объектов
Создает:
    Трубопроводы (createPipeline)
    Ветки с оросителями (createBranch)
    Рядки (createSprinklerRow)
    Узлы управления (createControlValve)
    Ориентированные цилиндры (createOrientedCylinder)
    Оси координат (createCustomAxes)

5. world.js - Управление миром
Управляет:
    Размером основания (зеленая плоскость)
    Сеткой координат
    Осями X, Y, Z

6. tree.js - Дерево объектов
Отображает:
    Иерархический список всех объектов на сцене
    Позволяет выбирать, скрывать, редактировать объекты

7. modules/project-manager.js - Управление проектами
Функции:
    Создание нового проекта
    Сохранение в папку (geometry.json + graph.json)
    Открытие/импорт проекта
    Экспорт/импорт данных

8. modules/scene-manager.js - Управление сценой
Управляет:
    Позицией камеры (сброс вида, вид сверху)
    Режимом камеры (перспектива/ортогональная)
    Видимостью сетки
    Настройками сцены

9. modules/pipeline-builder.js - Построитель трубопроводов
Интерактивное создание труб:
    Задание начальной точки
    Выбор оси (X/Y/Z) и направления (+/-)
    Добавление сегментов
    Предпросмотр
    Завершение/отмена

Workflow:
    Пользователь нажимает "Создать трубопровод"
    Открывается панель #pipelineBuilder
    Задает параметры (точка, ось, длина, DN)
    Нажимает "Добавить" → создается сегмент
    Повторяет пока не построит всю трассу
    Нажимает "Готово" → создается финальный объект

10. modules/object-editor.js - Редактор объектов
Позволяет:
    Менять позицию и поворот объектов
    Редактировать параметры (длины участков, диаметры)
    Дублировать объекты
    Привязывать объекты друг к другу
    Удалять объекты

11. modules/split-manager.js - Разбиение
Функции:
    Разбиение одного сегмента на несколько
    Разбиение всего трубопровода на новые сегменты
    Вставка узла управления в середину трубы

12. modules/network-graph.js - Граф сети
Визуализирует:
    Все узлы сети (точки соединения)
    Все связи (трубы, привязки)
    Авто-обнаружение близких узлов
    Экспорт в JSON

Алгоритм:
    Проходит по всем объектам
    Извлекает узлы (nodePositions)
    Строит граф (nodes + edges)
    Применяет force-directed layout
    Отрисовывает в SVG

13. modules/visual-effects.js - Визуальные эффекты
Управляет:
    Подсветкой объектов при наведении
    Режимом отображения диаметров (реальные/тонкие линии)
    Показом/скрытием узлов соединения

14. modules/input-handler.js - Обработка ввода
Обрабатывает:
    Клики мыши по canvas
    Перемещение мыши (для drag-and-drop)
    Горячие клавиши (Ctrl+S, Ctrl+O, B, R, P, V...)
    Raycasting (определение объектов под курсором)

15. modules/ui-app.js - Главный координатор
Центральный класс, который:
    Создает экземпляры всех менеджеров
    Инициализирует приложение
    Привязывает события кнопок ribbon-меню
    Координирует взаимодействие между модулями

Как всё работает вместе
Пример: Создание трубопровода

1. Пользователь нажимает "Создать..." в ribbon-меню
   ↓
2. ui-app.js → _bindRibbonButtons()
   ↓
3. menuCreatePipeline.onclick → this.pipeline.start()
   ↓
4. pipeline-builder.js → startPipeline()
   - STATE.pipeline.active = true
   - Показывает панель #pipelineBuilder
   ↓
5. Пользователь задает параметры и нажимает "Добавить"
   ↓
6. pbConfirm.onclick → this.pipeline.addSegment()
   ↓
7. addPipelineSegment()
   - Создает сегмент (start, end, diameter)
   - Factory.createOrientedCylinder() ← factory.js
   - Добавляет mesh на сцену ← Engine.scene
   ↓
8. Пользователь нажимает "Готово"
   ↓
9. finishPipeline()
   - Factory.createPipeline() ← создает Group из всех сегментов
   - STATE.objects.push({id, type, root, userData})
   - Tree.update() ← tree.js
   ↓
10. Готово! Трубопровод на сцене и в дереве объектов

 Ключевые принципы архитектуры

    Разделение ответственности - каждый модуль делает одну вещь
    Зависимости - модули загружаются в правильном порядке
    Глобальное состояние - STATE хранит все данные
    Координатор - UIApp управляет всеми модулями
    События - кнопки вызывают методы менеджеров
